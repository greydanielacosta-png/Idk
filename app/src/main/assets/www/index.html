Horizon Telemetry Radio

This Android wrapper is ready to host the content from the provided Google Drive file.

If the Drive file is public, tap Open Drive App in the Android toolbar. If it is private, download/export the content and place it in app/src/main/assets/www/.

Forza telemetry

Use UDP port 5300 for Forza data out. The native app can listen for speed, RPM, and gear while Spotify plays separately on Android.
