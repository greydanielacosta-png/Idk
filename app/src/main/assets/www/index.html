Spotify Connect + FH6 helper

FH6 Spotify Radio Companion

This APK helps your phone connect Spotify to the Forza Horizon 6 Spotify Radio PC mod workflow.

What this Android app does

  • Opens Spotify so you can select FH6 Radio in Spotify Connect.
  • Opens the PC mod dashboard at http://<PC-IP>:8103.
  • Listens for Forza UDP telemetry on port 5300 and shows speed/RPM/gear in the toolbar.

Required on the PC

  1. Install the Spotify Radio mod in the Forza Horizon 6 game folder where forzahorizon6.exe is located.
  2. Make sure version.dll and the spotify-radio folder are next to the game executable.
  3. Launch FH6, set Radio DJ Off and Streamer Mode On.
  4. Open Spotify on this phone and select FH6 Radio.

Important

The Android APK is a companion/controller. The actual in-game radio routing must happen on the PC mod. Spotify Premium is normally required for unofficial Spotify Connect playback.

If FH6 Radio does not appear

  • Put the phone and PC on the same local network.
  • Disable VPN, private DNS filtering, or network isolation.
  • Allow FH6/the mod through Windows Firewall on private networks.
  • Open the dashboard from this app and verify that the mod is running.
